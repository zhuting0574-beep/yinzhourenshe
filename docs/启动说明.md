# 本机启动

1. 执行 `mysql -uroot -p < database/schema.sql` 初始化数据库。
2. 启动 Redis 7：`redis-server`。
3. 启动后端：`cd server && mvn spring-boot:run`，端口 8081。
4. 启动管理端：`cd admin-web && npm install && npm run dev`，打开 http://localhost:5173。
5. UX 原型仍在 http://localhost:8080/。
6. 用微信开发者工具导入 `miniprogram/`。将 `app.ts` 的 `apiBase` 改为可访问的后端地址，并配置真实 AppID。
