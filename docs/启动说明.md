# 鄞领π本机启动说明

## 1. 环境

- Java 17、Maven 3.9+
- MySQL 8
- Node.js 20+
- 微信开发者工具（运行小程序时需要）

Redis 7 可启动，但当前业务不依赖 Redis 才能运行。业务时间统一使用 `Asia/Shanghai`。

## 2. 数据库与后端

先创建空数据库：

```bash
mysql -uroot -p < database/schema.sql
```

Flyway 会在首次启动后端时自动创建并升级所有业务表。设置数据库密码、管理员初始密码及开发密钥后启动：

```bash
cd server
export DB_USERNAME=root
export DB_PASSWORD='你的 MySQL 密码'
export ADMIN_USERNAME=admin
export ADMIN_PASSWORD='首次管理员密码'
export TOKEN_SECRET='至少 32 位的随机字符串'
export QR_SECRET='另一段至少 32 位的随机字符串'
mvn spring-boot:run
```

后端地址为 `http://localhost:8081`。管理员只会在 `admins` 表为空且设置了 `ADMIN_PASSWORD` 时创建，源码中没有默认明文密码。

开发环境默认开放模拟微信登录。生产部署必须设置：

```bash
export DEV_AUTH_ENABLED=false
export WECHAT_APP_ID='小程序 AppID'
export WECHAT_APP_SECRET='小程序 AppSecret'
export PUBLIC_BASE_URL='https://你的后端域名'
export UPLOAD_DIR='/安全的持久化上传目录'
```

## 3. Vue 管理端

```bash
cd admin-web
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。开发服务器会把 `/api` 代理到 `http://localhost:8081`。生产构建使用 `npm run build`，输出在 `admin-web/dist`。

## 4. 微信小程序

使用微信开发者工具导入 `miniprogram/`：

1. 在 `project.config.json` 配置真实 AppID。
2. 本机开发可保留 `app.ts` 中的 `http://localhost:8081/api`，并在开发者工具中关闭域名校验。
3. 真机与生产环境将 `apiBase` 改为已加入微信后台 request 合法域名的 HTTPS 地址。
4. 真实微信登录和手机号授权需要后端设置 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`；本机未配置时会回退到开发模拟账号。

## 5. UX 原型

UX 原型是视觉验收基准，不参与正式业务数据：

```bash
cd ux-prototype
python3 -m http.server 8080
```

打开 `http://localhost:8080`。

## 6. 验证命令

```bash
cd server && mvn test
cd admin-web && npm run build
```

MySQL 启动后还应人工验收：首次手机号绑定 +100、每日签到 +10、每自然月问卷一次 +100、报名后活动动态码核销 +100、重复操作不重复加分、兑换取消退款和 7 天逾期取消。
